# X1 GitHub Hero Specification

## Purpose

Every primary X1 repository hero must identify three things immediately:

1. this is X1;
2. what product/system this is;
3. whether it is public, commercial/private or internal.

## Canvas

Recommended:

- width: 1600 px
- height: 440–500 px
- outer radius: 28 px
- safe horizontal margin: 72–96 px

## Grid

Use a two-zone composition.

### Left identity zone

Contains:

- X1 mark
- category or system family
- thin signal line
- `SOFTWARE · SYSTEMS · OPERATIONS`

Target width: 34–40% of canvas.

### Right product zone

Contains:

- X1 micro-label
- product name or positioning headline
- short supporting line
- status/classification chips
- optional signal glyph

Target width: 60–66% of canvas.

## Hierarchy

Typical scale on a 1600 px canvas:

- X1 mark: 180–240 px
- product headline: 40–56 px
- micro-labels: 13–16 px
- support line: 18–24 px
- status label: 12–14 px

## Classification cards

Use compact outlined cards, not generic GitHub badges, inside the hero.

### Public

- cyan border
- label: `PUBLIC / FREE` or `PUBLIC / COMMUNITY`
- statement: `BUILT TO BE USED`

### Commercial / private

- electric-blue border
- label: `COMMERCIAL / PRIVATE`
- statement: `BUILT TO OPERATE`

### Internal

- violet border
- label: `PRIVATE ENGINEERING`
- statement: `CONTROLLED ACCESS`

## Product headline examples

- `DEVICE CONTROL. VERIFIED.`
- `CONFIGURE. DELIVER. VALIDATE.`
- `CONTROL THE SOFTWARE FLEET.`
- `VALIDATE BEFORE YOU PUBLISH.`
- `IDENTITY FIRST. ARTWORK SECOND.`
- `DEFINE STATE. VERIFY BEHAVIOR.`

These are patterns, not mandatory copy.

## Background treatment

Allowed:

- dark multi-stop gradient
- restrained scan lines
- circuit/data geometry
- low-opacity grid
- thin cyan/blue structural paths
- one small operational signal glyph

Avoid:

- bright gaming backgrounds
- excessive bloom
- stock photography
- unrelated 3D imagery
- multiple competing gradients
- giant decorative icons without system meaning

## Consistency rule

Product heroes may differ in diagram details and secondary accent, but these must remain stable:

- X1 left-zone identity
- dark enterprise shell
- cyan primary signal
- typography hierarchy
- status-card geometry
- bottom signature line

## Bottom signature

Recommended:

`X1 · SOFTWARE · SYSTEMS · OPERATIONS`

or for profile-level assets:

`X1 · PUBLIC SOFTWARE · PRIVATE ENGINEERING · ONE X1 IDENTITY`
