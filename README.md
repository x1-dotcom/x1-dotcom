## 🔐 Engineering principles

- **Secure by design** — explicit trust boundaries, signed artifacts and fail-closed behavior.
- **Performance first** — fast startup, efficient runtime and low unnecessary overhead.
- **Automation everywhere** — provisioning, OTA, validation and operational workflows.
- **One authority per concern** — avoid duplicated control planes and ambiguous state.
- **Community + commercial** — public projects can coexist with hardened commercial products.
